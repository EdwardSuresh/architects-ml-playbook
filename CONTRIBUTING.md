# Contributing

Thanks for helping learners!

- **Found a bug or unclear explanation?** Open an issue with the algorithm number and level (e.g. `07 / hard`).
- **Pull requests welcome** for fixes, clearer `# 🐍 PY:` / `# 🧠 ML:` comments, or translations.
- Keep every lab **self-contained** (generates its own synthetic data), **seeded**, and **under 60 seconds** on a laptop CPU.
- Run `python scripts/run_all.py` before opening a PR.
- Never add real customer, policy, patient or well data.
